Energia Solar Tecnologias

Sistema com Inversor String

Os painéis são conectados em série, enviando toda a energia para um único inversor central. Ideal para telhados amplos, sem sombreamento, com melhor custo‑benefício.

Sistema com Microinversores

Cada painel possui seu próprio inversor, operando de forma independente. Sombra ou sujeira em um módulo não afeta os demais. Máxima eficiência para telhados complexos e segurança máxima (normas dos Bombeiros).
